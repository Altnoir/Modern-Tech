# 加工台

在加工台中组合机器外壳和所需零件，制造机器。

<Recipe id="moderntech:processing_table/processing_table" />

将外壳放进单独的外壳槽，再把配方所需的零件放入配方图案指定的九宫格位置。零件可以在这些位置之间交换，但必须填满配方指定的位置，材料种类和数量也必须匹配。

<Recipe id="moderntech:steam_age/bronze/machine_casing_asbl" />

同一种机器的各个等级使用相同数量的零件。配方查看器展示的是一种有效摆法，你可以交换这些位置中的零件。多数机器还可以用旧机器和下一级机器外壳直接升级。
