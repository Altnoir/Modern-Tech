# ModernTech
欢迎来到**ModernTech**!

![ModernTech](/milogo.png)

## 序言
ModernTech 是一个关于自动化的模组！这意味着，在某个阶段，任何资源都可以（并且应该）实现自动化生产。

模组进度分为**蒸汽时代**（游戏前期）和其他剩余阶段。在蒸汽时代，你将创建第一批工厂，为后续阶段生产所需资源。这一阶段的挑战主要来自资源管理和生产流程的时间优化。

请注意，大多数蒸汽时代的设备都会在进入下一阶段后过时，因此不必在它们上面投入过多精力。

游戏进程的第二部分是**电气时代**。在这个阶段，强烈建议你自动化每一条产线。

这一阶段建造的设施可以通过更高等级的机器升级。各等级使用固定加工速度，配方会标明所需的最低机器等级。

挑战将来自于建立高效且平衡的产线，并优先处理最有用的部分。

ModernTech 的电动机器使用 FE，并提供标准的能源、物品和流体接口。请搭配其他模组的电缆和管道运输资源。固定速度机制支持按需自动化，持续运行不会逐步提高机器速度。
